# 并发检查与串口分层定位

## TSan启动

Ubuntu的高随机化地址布局可能与TSan影子内存冲突。验证器仅在私有测试进程族使用 `setarch x86_64 -R`，并核对测试前后的全局ASLR配置。

最终专项覆盖存储20、MQTT9、IPC11、诊断8项；启动探针、子进程退出与报告分类一起记录于[TSan结果](../evidence/results/stage6-tsan.json)。操作入口见[测试指南](TESTING.md)。

## UART分层定位

串口链路分为MCU发送、Windows COM、VirtualBox UART和guest tty四层。现场检查按供电、宿主枚举、VM映射、端口占用和raw/115200基线逐层进行。一次仅由一个接收器占用端口。

开发中曾出现启动积压和零输入；恢复配置后的短窗口及最终连续8小时在当前固定组合下通过。定位过程形成的工程经验是：同时保存原始流、源序号、MCU时间、Linux接收年龄及串口状态，依据实际字段区分积压、静默和解析错误。
